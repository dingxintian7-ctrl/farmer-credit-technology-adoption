# 数据质量检查与异常处理

| 质量维度 | 核查内容 | 处理原则 |
| --- | --- | --- |
| 完整性 | 必填字段、关键变量缺失率 | 先核对原始记录，再决定剔除、补录或填补 |
| 唯一性 | 样本编号重复 | 逐条核查；真实问卷不得自动合并 |
| 有效性 | 年龄、受教育年限、面积和量表取值 | 标记越界值，并依据原始问卷复核 |
| 一致性 | 0/1 编码、字段类型、取值口径 | 建立统一变量字典 |
| 可追溯性 | 随机种子、源数据和输出版本 | 脚本、输入和报告分目录管理 |

演示脚本包含字段缺失检查、样本编号唯一性检查、范围检查、缺失率统计和数据处理示例。

**注意：**代码中的中位数填补仅用于模拟数据的方法展示，不代表真实研究实际采用的缺失处理方式。真实分析须结合缺失机制和调查背景确定正式规则。

`tests/test_pipeline.py` 包括随机生成可复现性、重复编号拒绝、越界值拒绝及输出文件生成测试。
