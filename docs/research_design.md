# 研究设计与变量口径

## 真实项目与公开演示的区别

- **真实项目**：《信贷可得性对水稻种植户采用水肥一体化技术的影响》，国家级大学生创新训练项目。
- **实际参与**：整理核验 428 份有效问卷，使用 Stata 和 ESP 模型开展实证研究，参与结果解释。
- **公开仓库**：为展示可复现的数据处理方法，另行编写 Python 示例。所有记录均为模拟数据，变量并非原问卷的逐字段复制。

## 研究问题

围绕信贷可得性、农户生产条件与水肥一体化技术采纳展开，重点考察可能影响技术采纳的资金、教育、培训和成本因素。真实研究的识别策略及结果应以原报告为准。

## 模拟数据字典

| 字段 | 含义 | 演示口径 |
| --- | --- | --- |
| `respondent_id` | 样本编号 | 整数、非空、唯一 |
| `age` | 年龄 | 18–80 |
| `education_years` | 受教育年限 | 0–20；含少量模拟缺失 |
| `land_mu` | 耕作面积 | 正数；单位亩 |
| `training_attended` | 是否接受培训 | 0/1 |
| `perceived_cost` | 成本感知 | 1–5；含少量模拟缺失 |
| `credit_access` | 是否具有信贷可得性 | 0/1 |
| `adoption` | 是否采纳技术 | 0/1 |
| `region_group` | 模拟分组 | A/B/C；不代表实际地区 |

## 方法步骤

1. 明确字段、类型、取值范围、唯一性等数据口径。
2. 审计缺失、重复及越界情况；对模拟变量演示简化中位数填补。
3. 统计信贷分组的样本量与模拟采纳率。
4. 拟合普通二元 Logit，控制若干可观察变量。
5. 使用完整样本法进行示例敏感性检查。
6. 明确结论边界：Logit 系数仅表示模拟数据中的条件相关性，**不是因果影响**。

原项目的 ESP 模型涉及内生性与状态选择，本演示不复现该模型，也不披露原项目结果。
